## 🚀 Featured Engineering Projects

### 1. [Job Portal Platform (Distributed Microservices)](https://github.com/vivekkasaudhan/Job-Portal)
> **Stack:** `Next.js` • `TypeScript` • `Node.js` • `PostgreSQL` • `Apache Kafka` • `Docker` • `Redis`

- **Decoupled Architecture:** Designed dedicated independent microservices for `Auth`, `User`, `Job`, `Payment`, and `Utils` containerized with **Docker**.
- **Event Streaming:** Implemented **Apache Kafka** pub/sub event brokers for asynchronous notifications, resume intake, and distributed job queues.
- **Optimized Storage:** Dynamic multi-criteria PostgreSQL querying with Redis caching for ultra-low latency searches.
- 🔗 **Repository**: [github.com/vivekkasaudhan/Job-Portal](https://github.com/vivekkasaudhan/Job-Portal)

<br />

### 2. [AirBnb & Hotel Booking Platform (AI & Voice-Powered)](https://airbnb-frontend-per2.onrender.com/)
> **Stack:** `React.js` • `Node.js` • `Express.js` • `MongoDB Atlas` • `GROQ LLM` • `Web Speech API`

- **Multimodal AI Search:** Integrated **GROQ LLM API** allowing users to find stays through natural voice prompts like *"Show me the best hotel under ₹2000 in Delhi"*.
- **Hands-Free Voice Flow:** Implemented real-time browser speech recognition paired with dynamic speech synthesis feedback.
- **Production-Grade MERN:** JWT session protection, inventory state management, and deployed live on Render with MongoDB Atlas persistence.
- 🔗 **Live Demo**: [airbnb-frontend-per2.onrender.com](https://airbnb-frontend-per2.onrender.com/) • **Code**: [AIRBNB-project](https://github.com/vivekkasaudhan/AIRBNB-project)
